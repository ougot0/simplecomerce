# Textes à coller dans App Store Connect

Copiez chaque texte dans la case du même nom, dans App Store Connect, puis Apps, Simple Commerce, version 1.0.
Les nombres entre parenthèses donnent la longueur maximale autorisée par Apple.

## Informations sur l'app

- **Nom** (30) : `Simple Commerce`
- **Sous-titre** (30) : `Modifiez votre site vous-même`
- **Catégorie principale** : Économie et entreprise. **Catégorie secondaire** : Productivité.
- **Classification par âge** : répondez « Non » à toutes les questions, ce qui donne 4+.
- **Prix** : Gratuit.

**Description** (4000) :

```
Simple Commerce permet aux commerçants et aux artisans de mettre à jour leur propre site, sans rien connaître à l'informatique.

Vos produits, vos prix, vos stocks, vos photos, vos textes, vos horaires : tout se modifie depuis votre téléphone, en quelques secondes. Vous appuyez sur « Publier sur mon site », et c'est en ligne.

CE QUE VOUS POUVEZ FAIRE
• Ajouter, modifier ou retirer un produit
• Changer un prix ou un stock
• Prendre une photo avec votre téléphone et l'ajouter directement

• Fermer votre site pendant vos congés, avec un message pour vos clients
• Programmer une modification pour plus tard
• Voir les commandes et les avis de vos clients
• Revenir en arrière : chaque modification peut être annulée

POUR TOUS LES SITES
Votre site peut être hébergé n'importe où : chez OVH, o2switch, Hostinger, IONOS ou un autre hébergeur, ou encore sur WordPress, Shopify ou Webflow. Vous le reliez une fois, puis vous le retrouvez à chaque ouverture.

SIMPLE ET SÛR
• Pas de jargon : des boutons qui disent ce qu'ils font
• Vos accès sont chiffrés et ne sont jamais montrés
• Personne d'autre que vous et les personnes que vous invitez ne voit votre site

Un compte Simple Commerce est nécessaire. Il se crée sur simplecommercess.com.
```

## Confidentialité de l'app (questionnaire d'Apple)

- Collecte de données : **Oui**.
- **Coordonnées → Adresse e-mail** : utilisée pour le fonctionnement de l'app ; liée à l'identité de l'utilisateur ; pas de suivi.
- **Coordonnées → Nom** : mêmes réponses.
- **Contenu utilisateur → Photos** : mêmes réponses.
- Rien d'autre : pas de publicité, pas de mesure d'audience, pas de suivi.
